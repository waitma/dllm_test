**前缀核验通过。** natural 直接使用现有 `EpochRandomSampler` 的首 epoch 随机排列；equal-source 公式与现有 `FullCoverageSourceSampler` 连续轮转、源内无放回且耗尽后重洗的语义一致。独立 CPU 遍历两个真实采样器各 1,280,000 个整数索引，两个阶段全部来源呈现数、两个小来源的唯一行及重复数均与报告相同；三个记录的源码 SHA 均匹配当前文件。未读取序列或启动 GPU。精确性以排序后的同一来源行数、seed=42、从第 0 步开始的累计前缀、global batch=256 为条件；这不是实际训练消费日志。5000 步尚未跨过 natural 首 epoch。

**tempered 尚未实现。** `alpha=.5/.75` 只是按 `n_source**alpha` 计算概率与最大余数法整数配额，不是抽样器实测，更没有已实现的源内轮转语义。`.5` 的 native 配额为 1630/8152、trait 为 1871/9357；`.75` 分别为 248/1240、305/1525（1000/5000 步）。不得把这些配额称为已实现曝光，也不能据此声称唯一行覆盖或实测重复量。

对 pilot 的解释：固定数据、采样及随机种子有助于隔离架构差异，但结论仍只适用于该来源混合和训练预算。自然采样下小来源曝光不足，不能由总体提升推断小来源同样提升；等源的大量重复不代表获得更多独立信息，并改变了训练目标的来源权重。若后续测试 tempered 或 equal-source，应作为单独采样消融，固定架构和总预算，同时报告各来源验证指标、source macro、token micro 及实际曝光；不据本表强行选择 uniform，也不改变当前运行采样。合成诊断本身不能替代真实来源上的效果验证。
