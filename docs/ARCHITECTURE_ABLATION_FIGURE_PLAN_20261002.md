# 架构消融实验与最终对比图计划

状态：2026-10-02，预先登记的实验设计，尚无本轮GPU结果。它不阻塞已经确定的单因素实验启动。当前范围为通用架构的遮蔽重建比较；正式训练另行安排。

## 结论与依据

最终采用“单因素筛选 → 组合与交互 → 最终模型逐项去除”的设计，不能只画四根loss柱就声称完成整个模型消融。ConvNeXt展示了逐步改变设计并测量收益的研究路径；本项目额外加入组合与去除对照，避免累计改动顺序影响解释。[ConvNeXt原论文](https://arxiv.org/abs/2201.03545)

同一数据、预算和训练配方下的效果，回答“直接替换是否有用”；给各候选相同调参预算后的效果，回答“各自适配后是否更好”。两个问题分开画表。学习率等优化设置可能影响方法排名，不能把所有差异归因于结构。[Google Research调参指南](https://github.com/google-research/tuning_playbook)

初始化、抽样和超参数都有方差。初筛两个训练seed展示各点及范围，不以token数量冒充独立重复，也不把两点误差棒称稳定95%置信区间；确认阶段至少补至三个seed，排序不稳时补五个，报告均值、标准差及配对差值。数据只用一个子集种子时，结论明确限于此子集，不能声称覆盖数据抽样不确定性。[Accounting for Variance](https://arxiv.org/abs/2103.03098)

MAE分别研究遮蔽重建和表征评价，提醒我们不能用重建loss代替理解端成绩，也不能用一次全遮蔽预测代替迭代生成效果。它在图像上的遮蔽率选择不能直接当成这里的最优设置。[MAE原论文](https://arxiv.org/abs/2111.06377)

残差缩放参考CaiT/LayerScale的结构思路，但当前R24是固定标量缩放，不是完整复现其可学习LayerScale。论文结果不作为本项目有效性的证据。[CaiT原论文](https://arxiv.org/abs/2103.17239)

## 第二阶段：完整三因素矩阵及机制对照

要对这三个新增因素声称完整消融，必须覆盖全部八条件：000、100、010、001、110、101、011、111。四个组合条件尚未实现，后续需复用相同模块并验证，不能把planned标为done。若淘汰某因素而不跑完整矩阵，最终如实称为已选择因素的消融，不宣称三因素完整。

三因素八条件×至少3seed=24次同预算运行。首轮8次可复用，前提是数据、源码涉及的数值实现、训练设置和指标口径未变；还需至少16次补全。另追加R22固定0.5门控作为机制对照，区分动态门控收益与初始attention幅值缩小。固定残差缩放与学习率不存在普遍0.1倍等价；若要归因，给baseline和优选结构相同有限学习率搜索预算，并单独报告，不能只替候选调参。

完整矩阵可提取加法比较、两因素交互及111逐项去除（011、101、110）。以越低越好的loss为例，G与S交互为y110−y100−y010+y000；必须注明L=0及所有值来自同预算同seed。其他上下文可能不同，不能靠单项收益相加预测111。

位置编码、链身份编码、长度/终止机制、训练目标等现有设计不自动包含在上述“三因素完整”范围。如论文要对整个最终系统声称组件贡献，另列基线及这些模块的受控去除实验；输入表示或目标改变会改变指标分母，须统一可比较评价并单列兼容性限制。当前不为这些未定实验阻塞四项初筛。

## 最终图版与数据来源

1. **学习曲线**：横轴optimizer step及实际token曝光两个视图，纵轴固定验证mask平均AA CE；细线为seed，粗线为均值。只在共同已完成步数比较，保留失败/中断标记。
2. **单因素与去除组件图**：相对同seed baseline/完整模型的配对差值，显示全部seed点；AA、终止指标分开，不能以END改善掩盖AA退化。
3. **条件×来源热图**：四个mask比例分别展示token汇总及来源宏平均，注明各来源样本数。少数来源只有几条时显式标低样本，不能把宏平均稳定性夸大。
4. **三因素矩阵与交互图**：八条件及两因素差分，缺失条件留空并标未运行；不能填0、插值或用历史synthetic结果补格。
5. **效果—成本散点**：验证误差对训练GPU秒，另报eval耗时、tokens/s、峰值allocated显存和参数量。相同步数回答统计效率，相同GPU时间回答计算效率，两者都保留。
6. **理解与生成独立面板（待对应评测实际完成）**：使用独立、冻结且符合已有范围要求的评测协议。现有重建指标不能填此面板；没有结果就标未评测，不预测生物功能收益、不输出新设计序列。

当前主筛指标预登记为四mask平均AA CE（token汇总），同时必须报告来源宏平均与每mask/每来源结果；如果汇总与宏平均相反，标权衡，不能改主指标掩盖。现有terminal_accuracy只是在真实END位置的准确性，不代表终止精度、首次END位置或假阳性率。

最终输出SVG、PDF、PNG以及作图CSV/JSON和生成脚本；每个点关联run ID、seed、样本清单SHA、代码快照SHA、参数配置、步数、样本/token曝光、指标分母、状态。统计图只读实测日志，不手填成功值。初筛结束才能生成带数值的第一版图；当前仅计划与空白状态矩阵。
